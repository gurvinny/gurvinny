<sub><b>// FEATURED PROJECT</b></sub>

### SPECTRE — Wireless Intrusion Detection

<p>
  Dual-band <b>ESP32-C5</b> sensors running custom receive-only firmware stream 802.11 frames over native USB<br/>
  to a Python detection engine (deauth flood, evil twin, beacon/probe flood, RSSI anomaly).<br/>
  Scored threats route to <b>Wazuh over RFC 5424</b> and a Next.js SOC console — 3 of 4 rules mapped to <b>MITRE ATT&amp;CK</b>.
</p>
